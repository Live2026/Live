Live

Toute l'application, rassemblée

Tous les espaces de Live réunis dans une seule application : fil, Explorer, Market, Immo et séjours, Services, directs et créateurs, Live Savoir, Live Emploi, Live IA, messages et groupes, gains et outils, back-office. Chaque écran a été capturé automatiquement pendant un vrai parcours dans le prototype. Touchez une capture pour l'agrandir.

Prototype : données fictives, aucune transaction réelle. Mobile : téléphone de 360 px. Ordinateur : écran de 1280 px, avec barre latérale et deux colonnes ; le back-office n'existe que sur ordinateur.
