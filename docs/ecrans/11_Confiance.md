# Écrans — 11. Confiance : avis, signalements, réclamations

Ce qui distingue Live de Facebook : **un recours réel quand ça se passe mal**. Exigences : F-CONF-01 à F-CONF-07, F-MKT-CONF, F-IMMO-CONF, F-SRV-CONF.

---

## E-CONF-01 — Laisser un avis

```text
┌──────────────────────────────────────────┐
│ ✕  Votre avis                            │
├──────────────────────────────────────────┤
│ ▒▒ iPhone 11 64 Go                       │
│    Grâce Mode ✓ · reçu le 30/09          │
│                                          │
│ Note générale                            │
│       ★  ★  ★  ★  ☆                      │
│                                          │
│ Le produit était conforme ?              │
│       (Oui)   (En partie)   (Non)        │
│                                          │
│ Votre commentaire (facultatif)           │
│ [ Téléphone comme décrit, vendeuse       │
│   très sérieuse.                  ]      │
│                                          │
│ Photo (facultatif)  [ + ]                │
├──────────────────────────────────────────┤
│ Votre avis sera public, avec votre       │
│ prénom. Il aide toute la communauté.     │
├──────────────────────────────────────────┤
│ [        Publier l'avis          ]       │
└──────────────────────────────────────────┘
```

| Règle | Détail |
|-------|--------|
| Qui peut noter | Uniquement après une transaction **payée via Live** (F-CONF-01) |
| Critères | Services : ponctualité, qualité, propreté, respect du prix ; Immo : conformité de l'annonce, accueil |
| Modification | L'auteur peut modifier son avis pendant 7 jours ; le vendeur ne peut ni le modifier ni le supprimer (R-MKT-07) |

## E-CONF-02 — Signaler

```text
┌──────────────────────────────────────────┐
│ ✕  Signaler                              │
├──────────────────────────────────────────┤
│ Pourquoi signalez-vous cette             │
│ annonce ?                                │
│                                          │
│ ( ) Arnaque ou fausse annonce            │
│ ( ) Déjà vendu ou déjà loué              │
│ ( ) Demande de paiement hors Live        │
│ ( ) Produit interdit ou dangereux        │
│ ( ) Contrefaçon                          │
│ ( ) Contenu choquant ou violent          │
│ ( ) Harcèlement ou insultes              │
│ ( ) Autre                                │
│                                          │
│ Précisions (facultatif)                  │
│ [ ...                            ]       │
│ [ + Capture ou photo ]                   │
├──────────────────────────────────────────┤
│ Le signalement est anonyme pour la       │
│ personne signalée.                       │
├──────────────────────────────────────────┤
│ [         Envoyer                ]       │
└──────────────────────────────────────────┘
```

| Règle | Détail |
|-------|--------|
| Motifs | Adaptés à la cible (annonce, bien, profil, message, commentaire, vidéo) |
| Traitement | Motifs graves (arnaque, danger, mineurs) : file prioritaire ; plusieurs signalements concordants : suspension automatique de l'annonce avant revue (F-IMMO-CONF-05) |
| Suivi | L'auteur reçoit une notification quand une décision est prise |

## E-CONF-03 — Signaler un problème sur une commande, une visite ou une prestation

```text
┌──────────────────────────────────────────┐
│ ◀  Un problème avec la commande ?        │
├──────────────────────────────────────────┤
│ ▒▒ iPhone 11 · 80 000 FCFA bloqués       │
│ Délai pour signaler : 41 h restantes     │
│                                          │
│ Que se passe-t-il ?                      │
│ ( ) Je n'ai pas reçu le produit          │
│ (•) Le produit ne correspond pas         │
│ ( ) Le produit est défectueux            │
│ ( ) Je pense que c'est une               │
│     contrefaçon                          │
│                                          │
│ Expliquez                                │
│ [ Écran rayé alors que l'annonce         │
│   disait aucune rayure.           ]      │
│                                          │
│ Preuves (obligatoire)                    │
│ [ ▒▒ ] [ ▒▒ ] [ + ]                      │
│                                          │
│ Ce que vous souhaitez                    │
│ ( ) Rendre le produit, être remboursé    │
│ (•) Garder le produit, remboursement     │
│     partiel : [ 15 000 ] FCFA            │
├──────────────────────────────────────────┤
│ L'argent reste bloqué jusqu'à la         │
│ solution.                                │
├──────────────────────────────────────────┤
│ [      Envoyer au vendeur        ]       │
└──────────────────────────────────────────┘
```

| Règle | Détail |
|-------|--------|
| Étape 1 : accord amiable | Le vendeur a 48 h pour accepter, refuser ou proposer autre chose (F-MKT-CONF-03) |
| Étape 2 : médiation | Sans accord : bouton « Demander l'aide de Live » ; un agent décide sur la base des preuves |
| Variantes | Immo : « Le bien ne correspond pas », « L'annonceur n'est pas venu » ; Services : « Absent », « Travail non terminé », « Malfaçon », « Différent du devis », « Dégâts » |

## E-CONF-04 — Suivi de la réclamation

```text
┌──────────────────────────────────────────┐
│ ◀  Réclamation R-2026-0192               │
├──────────────────────────────────────────┤
│ iPhone 11 · 80 000 FCFA bloqués          │
│                                          │
│  ✓ Réclamation envoyée      30/09        │
│  ✓ Réponse du vendeur       30/09        │
│  ● Médiation Live en cours               │
│  ○ Décision                              │
│                                          │
│ Grâce Mode (vendeur) :                   │
│ « La rayure était signalée dans la       │
│ description. Je propose 5 000. »         │
├──────────────────────────────────────────┤
│ Votre réponse et vos preuves             │
│ [ Écrire...                      ]       │
│ [ + Ajouter une preuve ]                 │
├──────────────────────────────────────────┤
│ Agent Live : décision sous 72 h au       │
│ plus tard. Vous serez prévenu.           │
├──────────────────────────────────────────┤
│ ( Accepter l'offre de 5 000 FCFA )       │
└──────────────────────────────────────────┘
```

| Règle | Détail |
|-------|--------|
| Échanges | Tout est écrit et horodaté dans la réclamation ; les messages de la conversation d'origine sont joints au dossier |
| Décision | Remboursement total, remboursement partiel ou versement au vendeur ; motivée et notifiée aux deux parties (F-CONF-04) |
| Après la décision | Possibilité de demander un réexamen une seule fois, avec un élément nouveau |
