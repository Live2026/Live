## E-MOI-05 — Équipe de l'espace

```text
┌──────────────────────────────────────────┐
│ ◀  Grâce Mode · Équipe                   │
├──────────────────────────────────────────┤
│ Membres (3 / 5)                          │
│ ( ▒) Grâce Mabiala   Propriétaire        │
│ ( ▒) Nadège Loubaki  Gestionnaire  ⋮     │
│ ( ▒) Junior Mouanda  Vendeur       ⋮     │
├──────────────────────────────────────────┤
│ Invitations en attente                   │
│ 06 777 88 99 · Vendeur   (Annuler)       │
├──────────────────────────────────────────┤
│ ( + Inviter un membre )                  │
│                                          │
│ Ce que chaque rôle peut faire   ▶        │
└──────────────────────────────────────────┘
```

| Rôle | Droits |
|------|--------|
| Propriétaire | Tout, y compris les retraits et la suppression de l'espace |
| Gestionnaire | Annonces, commandes, messages, équipe (sauf le propriétaire) ; pas de retrait |
| Vendeur / Agent | Ses annonces, ses commandes ou visites, ses messages |
| Comptable | Consultation des gains et export ; aucune action |
