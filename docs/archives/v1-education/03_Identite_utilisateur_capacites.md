# Document 03 — Identité utilisateur, profil évolutif et système de capacités

# 1. Philosophie

Live repose sur un principe unique :

> Tout le monde est un utilisateur.

Aucun compte "enseignant", "école", "université" ou "ONG" n'existe lors de l'inscription.

Chaque utilisateur fait évoluer son compte au fil du temps.

---

# 2. Les principes fondamentaux

- Un seul type de compte.
- Une seule identité.
- Un seul portefeuille.
- Un seul historique.
- Les fonctionnalités évoluent avec le compte.
- Les droits sont accordés sous forme de capacités.
- Le Super Administrateur est le seul rôle permanent.

---

# 3. Cycle de vie d'un utilisateur

Étape 1 : Création du compte
- Téléphone ou e-mail
- Vérification OTP
- Acceptation des conditions

Étape 2 : Profil personnel
- Nom
- Photo
- Pays
- Ville
- Niveau d'études (optionnel)
- Centres d'intérêt

Étape 3 : Utilisation
- Consultation
- Recherche
- Visionnage
- Commentaires
- Sauvegardes

Étape 4 : Évolution
L'utilisateur peut demander de nouvelles capacités.

Exemples :
- publier des vidéos ;
- créer des cours ;
- ouvrir Live Studio ;
- représenter une organisation ;
- vendre des contenus ;
- organiser un direct.

---

# 4. Les capacités

Une capacité est une autorisation supplémentaire.

Exemples :

- Publier une vidéo
- Publier un PDF
- Créer un QCM
- Créer une série
- Ouvrir un direct
- Recevoir des paiements
- Représenter une organisation
- Publier un résultat officiel
- Publier une opportunité
- Accéder aux statistiques avancées
- Utiliser certaines fonctions IA avancées

Les capacités peuvent être obtenues par :
- abonnement ;
- vérification ;
- validation administrative ;
- partenariat ;
- réussite d'un processus qualité.

---

# 5. Comptes vérifiés

Certaines identités peuvent demander une vérification.

Exemples :

- Enseignant
- Établissement
- Université
- Ministère
- ONG
- Entreprise
- Média

La vérification ajoute un badge officiel mais ne crée pas un nouveau type de compte.

---

# 6. Représentation d'une organisation

Un utilisateur peut représenter une organisation.

Une même organisation peut disposer de plusieurs gestionnaires.

Toutes les actions sont historisées.

---

# 7. Abonnements

Les abonnements n'accordent pas un rôle.

Ils débloquent des capacités.

Exemples :

- Live Studio
- Statistiques
- Monétisation
- IA avancée
- Directs

---

# 8. Sécurité

Avant certaines actions :

- vérification d'identité ;
- validation Mobile Money ;
- contrôle anti-fraude.

Les capacités sensibles peuvent être suspendues sans fermer le compte.

---

# 9. Journal des actions

Chaque opération importante est enregistrée :

- connexion ;
- publication ;
- paiement ;
- retrait ;
- modification ;
- validation ;
- suspension.

---

# 10. Objectif

Le compte Live accompagne l'utilisateur durant toute sa vie scolaire, universitaire, professionnelle et entrepreneuriale.

Le compte ne change jamais ; seules les capacités évoluent.
