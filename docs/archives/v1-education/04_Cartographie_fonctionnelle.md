# Document 04 — Cartographie fonctionnelle complète de Live

# Objectif

Définir l'ensemble des modules constituant l'écosystème Live, leurs responsabilités, leurs interactions et leur ordre de réalisation.

---

# Architecture générale

Live est construit comme une plateforme modulaire.

Chaque module est indépendant mais interconnecté.

Un utilisateur peut utiliser un seul module ou l'ensemble de la plateforme avec une identité unique et un portefeuille unique.

---

# Les modules de Live

## 1. Live Feed

### Mission
Point d'entrée principal de l'application.

### Fonctionnalités
- Fil personnalisé
- Recommandations
- Vidéos
- Publications
- Actualités
- Contenus sponsorisés
- Reprise de lecture

### Dépendances
Live Learn, Live Community, Live Opportunity, Live Exam.

---

## 2. Live Exam

### Mission
Publier et consulter les examens et résultats officiels.

### Fonctionnalités
- Calendriers
- Résultats
- Relevés
- Vérification d'authenticité
- Notifications

### Revenus
Services institutionnels.

---

# Dépendances stratégiques

Les modules centraux sont :

- Live Wallet
- Live Studio
- Live AI

Ils alimentent économiquement toute la plateforme.

Les modules d'attraction sont :

- Live Exam
- Live Opportunity
- Live Learn

Les modules de fidélisation sont :

- Live Feed
- Live Community
- Live Direct

# Conclusion

Chaque module possède sa propre logique métier mais tous partagent :

- une identité unique ;
- un portefeuille unique ;
- une expérience utilisateur cohérente ;
- une architecture évolutive.
